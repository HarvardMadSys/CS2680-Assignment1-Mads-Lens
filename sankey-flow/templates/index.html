TTFT — time to first token: from the request (run start, or the last tool result handed back to Claude) until the first streamed token arrives.

TPOT — time per output token: the message's streaming time divided by its tokens minus one. tokens/s is its inverse, smoothed.

Latency — how long the last tool call took (tool_use → tool_result), and the last full API turn (request → end of the reply).

The cat sleeps when idle, waits for the first token or a tool, walks under 25 tokens/s and runs at or above it.

Policy · no limits
Budget cap (USD)

Sent as --max-budget-usd. Claude checks the cap after each turn and ends the run with “hit the cost budget” once it is exceeded, so one turn can overshoot a tiny cap.

Allowed tools

Sent as --tools, which only covers Claude's built-in tools. Everything checked means no restriction (the flag is omitted). MCP tools are not affected; deny them by pattern below.

Deny patterns

Comma-separated, sent as --disallowedTools. Tool names or Tool(pattern) rules, e.g. Bash(git push *), Edit, mcp__server__tool. Up to 50 rules of 200 characters.
